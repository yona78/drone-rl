# Usability — Nielsen Heuristics & UI/UX Decisions

## Nielsen's 10 Usability Heuristics Applied

1. **Visibility of system status** — Real-time episode counter, progress bar, convergence chart
2. **Match between system and real world** — Grid uses familiar colors (gray=concrete, red=danger, blue=wind)
3. **User control and freedom** — Pause/resume/reset training at any time
4. **Consistency and standards** — Standard tkinter widgets; familiar slider/button patterns
5. **Error prevention** — Grid editor validates placement; cannot place start on goal
6. **Recognition rather than recall** — Obstacle palette with color-coded labels
7. **Flexibility and efficiency of use** — Keyboard shortcuts for power users
8. **Aesthetic and minimalist design** — Clean layout; information density without clutter
9. **Help users recognize, diagnose, recover from errors** — Status bar messages for invalid actions
10. **Help and documentation** — Tooltips and README reference
